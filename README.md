# hisho-support

iOSアプリ「秘書検定 一問一答」のサポートページ（GitHub Pages）。

- `index.html` サポート（無料範囲・購入内容・FAQ・問い合わせ導線）
- `terms.html` 利用規約
- `privacy.html` プライバシーポリシー
- `style.css` アプリと同じ意匠（レザー・箔押し・リフィル紙）

公開URL: https://yuuki45.github.io/hisho-support/

アプリ側の参照箇所: `HishoApp/App/HishoApp.swift` の `AppConfig`（supportURL / termsURL / privacyURL）。
実数・URLの正は `~/dev/hisho-app/docs/project_facts.md`。
